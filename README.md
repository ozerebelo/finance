# Household Finances

`Household_Finances.xlsx` - a shared budget, savings and expense workbook for two people.

| Tab | Purpose |
|---|---|
| Dashboard | Pick a month/year; KPIs, charts, savings goals, 12-month overview |
| Budget | Monthly budget per category vs actual, status flags, year-to-date |
| Savings | Goals with target dates, progress, "on track / behind", contribution log |
| Annual Bills | Sinking fund: yearly bills spread over 12 months, monthly set-aside, fund balance vs what you should have saved, payment log |
| Transactions | One shared log of income and expenses (dropdowns for category and who paid) |
| Monthly Review | End-of-month analysis: plain-English highlights, vs last month, by group/category, top 5 expenses, by person |
| Setup | Names, currency label, target savings rate, warning threshold, lists |
| Guide | Step-by-step instructions |

Blue text on yellow = you type. Grey = fills itself. The file ships with **sample data** (Sep-Oct 2026): delete the yellow cells in Transactions (A-F) and the Savings log to start fresh.
Capacity: 1,000 transactions, 500 savings entries and 200 annual-bill payments. Works in Excel, and in Google Sheets / OneDrive for sharing.
